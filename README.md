# TKinter GUI Application
This is a simple GUI application built using Python's Tkinter library. It includes a menu system with File, Edit, and Help options

# Features
1.Graphical User Interface (GUI) using Tkinter
2.File menu with options like New Project, Save, Save As, and Open
3.Edit menu with Copy, Cut, Paste, and Find options
4.Help menu with Help and Rate Us features

# Usage
1.The application window opens with a menu bar.
2.Click on File, Edit, or Help to see available options.
3.The Help menu shows an information box when clicked.
4.The Rate Us option asks a question about the user experience.
